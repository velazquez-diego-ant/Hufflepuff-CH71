#  Hackathon: Casas de Hogwarts

##  Descripción del Proyecto

Hackathon de las Casas de Hogwarts es una aplicación web inspirada en el universo mágico de Harry Potter, donde los usuarios pueden explorar productos relacionados con las casas de Hogwarts, visualizar detalles de productos, agregarlos a un carrito de compras y participar en procesos de reclutamiento para formar parte de una casa.
El proyecto combina diseño atractivo, experiencia de usuario intuitiva y componentes interactivos para crear una experiencia mágica inspirada en Hogwarts.
